# LL.B. Study Library

A structured, long-term study library for the LL.B. programme. Materials are organised by **semester → subject → study day → topic**, with separate areas for syllabus documents, class notes, statutory provisions, case law, previous-year papers, predicted questions, model answers, revision and mock tests.

> **Public repository:** Do not add personal information, passwords, access tokens, private college documents, or copyrighted textbooks/paid notes. Prefer official public sources and original summaries.

## Quality labels

- **Official source:** directly published by a university, legislature, court or government.
- **Verified PYQ:** wording checked against an actual question paper with year/session and source recorded.
- **Predicted question:** a syllabus-based practice question, not claimed to have appeared in an exam.
- **Practice question:** created for learning and self-testing.
- **Needs verification:** a point or source that still needs checking.

## Content preservation

New material should be added as new files or append-only additions wherever practical. Do not replace a complete note or question bank merely to add a new topic. Corrected legal statements should include a dated note in the relevant change log, with the old text retained when needed for auditability.
