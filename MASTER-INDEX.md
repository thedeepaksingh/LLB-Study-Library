## Find content quickly
Use GitHub repository search with:
- `DAY-01`, `DAY-02`, etc. for day-level lessons
- `TOPIC-` for stable topic identifiers
- `PYQ-VERIFIED` only for questions traced to a real paper
- `PREDICTED` for syllabus-based likely questions
- `PRACTICE` for original exercises
- `CASE-` for case-law records
- `SECTION-` for section-wise BNS notes

## Evidence labels
Every question-paper entry should say whether the original paper has been inspected. A third-party listing alone is not enough to mark a question as a verified previous-year question.
