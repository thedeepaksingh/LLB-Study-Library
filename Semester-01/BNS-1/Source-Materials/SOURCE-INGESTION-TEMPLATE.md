## Required outputs
- [ ] Keep original file unchanged in the source-of-record location.
- [ ] Create a full text extraction, preserving content order, heading labels, tables and visible page markers as far as the extraction format allows.
- [ ] Check extracted text count/length and confirm the final range is present.
- [ ] If tables/figures/images exist, record their count and extraction limits. Do not silently drop non-text content.
- [ ] Split long transcripts into ordered parts, with a manifest showing exact range boundaries.
- [ ] Link all parts from a source README.
- [ ] Keep the transcript separate from rewritten notes and legal/subject-matter corrections.
- [ ] Record each action in the subject changelog and repository changelog.
- [ ] Run local-link and file-integrity checks.
- [ ] Open a feature branch and review pull request; do not merge without approval for that specific PR.

## Source-preservation constraints
- Do not paraphrase, spell-correct, update section numbers, rearrange headings, remove repetition, or replace source text with model knowledge.
- Do not label an extraction “verbatim” where the source layout, images, equations or tables were not fully preserved.
- Put any correction, legal update, explanation or syllabus alignment in a separate authored file with sources and date.
- Distinguish source claims from verified law and from assistant inference.
- For future files, reproduce this intake structure rather than inventing a new storage arrangement each time.
