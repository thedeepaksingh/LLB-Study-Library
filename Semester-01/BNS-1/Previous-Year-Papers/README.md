# BNS-1 Previous-Year Papers (PYQs)

## Verification policy
A third-party index or search result is a lead, not proof that a specific question appeared in a CCSU exam. The actual paper must be inspected before an item is labelled a verified PYQ.

## How to add a paper
1. Record exam year/session, programme, semester and paper code.
2. Store a permissible copy or reliable link to the actual paper.
3. Transcribe wording carefully; label paraphrases as paraphrases.
4. Link each question to a syllabus topic and model answer.
5. Mark verified only after checking the original question paper.

A syllabus, summary, or predicted question is not a PYQ.
