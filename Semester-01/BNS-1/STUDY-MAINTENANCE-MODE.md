# Study-First Repository Maintenance Agreement

## User's role

The repository owner wants to focus on learning, not coding, folder management, branch operations or manual uploads.

## Maintainer's responsibilities

For this workflow, the assistant should handle repository work wherever the connected GitHub tools permit it:
- inspect files before changes;
- keep all BNS-1 material under this canonical subject directory;
- organise material by syllabus topic, study day and exam resource;
- maintain indexes, changelogs, question IDs and source registers;
- create a dedicated branch for each logical update;
- validate changes and prepare a pull request;
- report what changed, what was checked and what remains incomplete;
- wait for explicit approval of the specific PR before merging it to main.

The user should not be asked to manually write Markdown, create folders or operate Git commands as part of ordinary study-material maintenance. Ask for manual actions only when the connected integration genuinely lacks a required permission or capability, and explain the limitation clearly.

## User's approval role

The user learns from the material and approves or requests changes to proposed publication changes. Explicit approval means approval of a specific PR after a review summary has been provided. General permission to maintain the library is not blanket permission to merge every future change.

## Subject completeness requirement

Keep all BNS-1 content within Semester-01/BNS-1/, using subfolders for navigation. Do not scatter BNS-1 notes into a different repository or unrelated subject directory. The subject dashboard and [Content Completeness Matrix](CONTENT-COMPLETENESS-MATRIX.md) serve as the main navigation points.

A topic is not complete just because a file exists. Mark it verified only after the syllabus, statutory sections, exceptions, relevant cases and exam questions have been reviewed. Track pending work explicitly.

## Perfection and legal accuracy

Do not promise perfection. Apply a documented quality-review process, identify unresolved issues and correct errors transparently. Legal material should prioritise official legislation and the applicable CCSU syllabus over secondary summaries.
