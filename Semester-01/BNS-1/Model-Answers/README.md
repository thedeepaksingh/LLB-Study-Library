# BNS-1 Model Answers

## Standard university answer structure
1. Introduction / definition.
2. Correct BNS provision, checked against the official Act.
3. Essential ingredients.
4. Explanation of each ingredient.
5. Illustration or application to facts.
6. Relevant verified case law, where useful.
7. Conclusion that directly answers the question.
