# DAY-02 — Liability and Inchoate Offences

**Status:** Topic roadmap; detailed lesson to be added.  
**Topics:** Strict liability, constructive/group liability, common intention, common object, abetment, criminal conspiracy and attempt.

## Study targets
- Distinguish common intention from common object.
- Learn statutory rules for abetment, conspiracy and attempt using the current BNS text.
- Work through hypothetical problems involving group liability.
- Separate the mental element from the statutory conditions for each doctrine.

## Statutory starting points — verify full wording
- **Section 3(5):** acts done by several persons in furtherance of common intention.
- **Sections 45 onward:** abetment provisions.
- **Section 61:** criminal conspiracy.
- **Section 62:** attempt provision for the cases it covers.
- **Section 190:** liability in relation to certain offences committed by a member of an unlawful assembly, subject to statutory conditions.

Read the full provision and relevant definitions in the [official BNS Act](../Bare-Act-and-References/official-sources.md).
