# BNS-1 Quick Revision Sheets

This shelf is for short revision materials created after the full lesson is understood.

Recommended file format:
- `REV-01-Stage-of-Crime.md`
- `REV-02-General-Exceptions.md`
- `REV-03-Homicide-Comparison.md`
- `REV-04-Property-Offences-Comparison.md`
- `REV-05-Sections-to-Recall.md`

Every sheet should link to the full notes, identify statutory provisions that need verification, and avoid oversimplifications that change the legal test. Summaries supplement the full notes; they do not replace them.
