## Timed practice method
1. Use the exam duration and marks pattern only after checking an authentic CCSU paper or official instructions.
2. Attempt a balanced mix of long answers, short notes, comparisons and problem questions.
3. Do not consult the answer key while writing.
4. Assess each answer for legal accuracy, ingredients, organisation, application and conclusion.
5. Add mistakes to an error log and revisit the relevant topic.
