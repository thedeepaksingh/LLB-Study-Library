# Question Bank — Answer Keys

Keep answer keys separate from the question statements when self-testing is intended. Each answer should link back to its question ID and subject note.

## Answer key format
- **Question ID:**
- **Correct answer / outline:**
- **Reasoning:**
- **Relevant BNS provision (verified):**
- **Common error:**
- **Source/verification note:**

Do not make an answer sound certain when the question lacks facts needed for a legal conclusion. Distinguish short recall answers from full university exam answers.
