# Verified Previous-Year Questions — BNS-1

Only questions checked against the actual CCSU examination paper belong here.

## Required record for every paper
- Exam year and session
- Course/programme and semester
- Paper title/code as shown on the paper
- Exact question wording (or explicitly marked paraphrase)
- Marks, if visible on the source paper
- Source URL or paper file
- Date checked and verification note
- Links to the syllabus topic and model answer

## Current status
**No verified PYQs have been added yet.** A third-party paper listing, syllabus or question prediction is not enough to verify a question. Do not copy unverified questions into this shelf.
