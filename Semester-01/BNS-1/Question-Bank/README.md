# BNS-1 Question Bank

## Authenticity labels
- **Verified PYQ:** wording checked against an actual CCSU paper, with year/session and source.
- **Listed, unverified:** a third-party site lists a paper but its actual text has not been inspected.
- **Predicted:** syllabus-based likely question, not a claim that it appeared in an exam.
- **Practice:** original study exercise.

## Starter set — Day 1 (predicted/practice only)
1. Define crime and explain its essential elements.
2. Explain actus reus and mens rea.
3. Describe the four stages of crime.
4. Distinguish preparation from attempt.
5. Distinguish a criminal wrong from a civil wrong.

These questions are not verified previous-year questions. Link every later question to its topic note and model answer. Keep original question text and source information when recording actual papers.
