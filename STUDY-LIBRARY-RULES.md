# Study Library Rules — Keep Content Intact

These rules apply to every semester and subject in this repository.

## 1. Folder convention
`Semester-XX/Subject-Code/` → day/topic folders → notes, questions, answers and references.

## 2. Preserve before extending
- Do not replace an entire notes file just to add a new topic.
- Prefer a new file for each separate topic and append genuinely new questions to the appropriate question bank.
- Before editing any existing file, fetch and read the current version.
- If a substantive legal correction is needed, record the date, reason and affected passages in `CHANGELOG.md`.
- Retain the old version or a clearly labelled superseded copy when the change affects exam preparation or legal accuracy.
- Never delete question-bank entries just because they are repeated; mark duplicates and cross-link them unless removal is specifically necessary.

## 3. Stable identifiers
Use identifiers that do not change when a title is refined:
- Lessons: `DAY-01`, `DAY-02`
- Topics: `TOPIC-BNS1-001`
- Questions: `PREDICTED-BNS1-001`, `PRACTICE-BNS1-001`
- Verified past questions: `PYQ-VERIFIED-BNS1-YYYY-001`
- Cases: `CASE-BNS1-001`

## 4. Question authenticity
- **Verified PYQ:** the question text and year/session have been checked against an actual paper; record the source URL or file.
- **Third-party listing only:** mark as `listed—paper not inspected`, not verified.
- **Predicted:** original syllabus-based suggestion; never describe it as previously asked.
- **Practice:** original learning exercise.
- If exact wording is uncertain, paraphrase and identify it as a paraphrase.

## 5. Legal source hierarchy
Prioritise legislation as published on India Code, the official CCSU syllabus, judgments from official court sources, and reputable legal reports. Record access dates where relevant. Check statutory wording and amendments before memorising section numbers or punishments.

## 6. Public repository
This repository is public. Do not commit personal identifiers, credentials, private correspondence, copyrighted books, paid coaching notes or full copyrighted content without permission. Write original summaries and link to lawful official sources.

## 7. Every new subject should have
- subject dashboard and official syllabus;
- navigation index;
- topic-wise notes;
- question bank separated by authenticity;
- model answers;
- case-law register where relevant;
- previous-year-paper source register;
- quick revision and mock test;
- source list and change log.

## 8. Changelog
Record significant additions and corrections in the subject-level `CHANGELOG.md`, including what changed and why.
